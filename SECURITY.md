# Security policy

Version 1.x is the supported project line. The detector evaluates one CVE in
official Node.js artifacts; it does not certify entire systems as safe.

For a security defect in this tool, use private vulnerability reporting on GitHub
if enabled. If unavailable, request a private contact channel in an issue without
posting sensitive evidence or working exploit payloads. Include tool/Python
versions, sanitized reproduction steps, assessment scope and the impact.

Misclassification reports should identify the evidence provenance and distinguish
runtime binaries from archives, installers and running processes. Do not publish
private paths, customer data, credentials or production reports.

Maintainers should enable private vulnerability reporting before public release.
No fixed response-time commitment is implied.
